# Dairy Farm System

Livestock management for a dairy farm in Villupuram: herd, breeding, health, feed, milk yield and finances.

- Frontend: React + Vite (`/frontend`)
- Backend: Spring Boot 4, Java 21 (`/backend`)
- Database & auth: Supabase

See `PLAN.md` for the build plan, `PROGRESS.md` for status, and `/docs` for the design.
